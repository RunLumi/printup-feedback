# PrintUp Feedback

Kho tiếp nhận phản hồi nội bộ cho **PrintUp**.

Dùng GitHub Issues để QC, QA, PM, Thiết kế, Kỹ thuật và Vận hành ghi nhận:

- lỗi;
- tính năng mới;
- cải tiến;
- thay đổi `biz-docs`;
- phản hồi thiết kế / UX.

👉 **[Tạo đề xuất mới](https://github.com/RunLumi/printup-feedback/issues/new/choose)**

📘 **[Hướng dẫn gửi và xử lý issue](./.github/ISSUE_FORMS.md)**

## Lưu ý bảo mật

**Repo hiện đang public.** Issue và tệp đính kèm có thể được xem công khai.

Không đăng:

- mật khẩu, token, khóa API;
- thông tin thanh toán;
- dữ liệu cá nhân không cần thiết;
- dữ liệu khách hàng hoặc tài liệu nội bộ chưa được phép công khai;
- log chưa che thông tin nhạy cảm.

Nếu repo được dùng đúng nghĩa như một hệ thống phản hồi nội bộ có dữ liệu thật, nên chuyển repo sang **private**.

## Nguyên tắc

Một issue tốt phải trả lời được 5 câu hỏi:

1. Vấn đề là gì?
2. Bằng chứng ở đâu?
3. Ảnh hưởng tới ai và mức nào?
4. Kết quả mong muốn là gì?
5. QA/QC kiểm tra thế nào để xác nhận hoàn tất?
